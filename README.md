# Potatoes PC

Developer website for Potatoes PC games: https://ayanhussain2423.github.io

- `app-ads.txt`: tells ad buyers which ad accounts may sell ads in our apps (IAB app-ads.txt standard).
- `index.html`: small home page.
- `bloop-zoo/privacy.html`, `bloop-pets/privacy.html`: the games' privacy policies (also the links on Google's sign-in screen for Play Games).

No app source code lives here.
